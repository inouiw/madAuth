One Tap / FedCM Server-side redirect

new GoogleFedcm(): the browser shows “Continue as …” (One Tap) and the madAuth server verifies Google's ID token.

new GoogleRedirect(): the browser is redirected to Google and back, and the madAuth server exchanges the code. Needs GOOGLE_CLIENT_SECRET on the server.

This madAuth server doesn't offer the redirect flow: it needs GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET, with Google switched on. The dialog offers e-mail & password only.
